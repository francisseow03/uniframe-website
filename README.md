# Uniframe Systems website

Static one-page site, no build step. The hero is a scroll-scrubbed sequence of 120 Blender renders (`frames/`): the wall builds itself and ends on the "Built to fit your floor" panel. Design source: Figma file fKLcysEZcNHpCDGxXOONMf, page 02 Website, Home v4.

Photos: Unsplash License (Craig Lovelidge, Francesco Liotti, Domingo Alvarez E, Cemrecan Yurtman, Hammer Group). The quote form opens the visitor's email app addressed to info@uniframe.nl; there is no server.
